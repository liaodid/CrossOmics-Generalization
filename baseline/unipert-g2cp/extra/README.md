# extra/：复现仓库之外的原作者源码

放 UniPert‑G2CP 作者提供、但复现仓库 `lynn-1998/UniPert-G2CP_reproduce` 中没有对应位置的代码，
例如数据预处理脚本、额外的分析代码。

先看 [../README.md 第 11 节](../README.md#11-补充原作者源码放在哪里)，确认这份代码是否应放在
`UniPert/`、`G2CP/` 或 `analysis_assets/` 中与作者原始目录一致的位置。只有找不到对应位置时才放这里。

## 放置方式

- 每个来源一个子目录：`extra/<来源名>/`，名字用小写加短横线，如 `extra/lincs-preprocessing/`。
- 子目录内保持作者原始的文件结构和文件名，第一次提交不做任何修改。
- 数据、权重、中间结果不进 Git，放到 `data/unipert-g2cp-zenodo/raw/`。
