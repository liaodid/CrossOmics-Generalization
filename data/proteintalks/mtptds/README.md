# mtPTDS：ProteinTalks 多时间点数据集

mtPTDS 是 Multi-time-point ProteinTalks Dataset 的缩写（Reporting Summary 原文）。总体来源、获取方式和代码输入格式见上一级 [README](../README.md)。

## 内容（摘自论文 Methods 与 Reporting Summary，2026‑10‑15 核对）

| 项目 | 内容 |
|---|---|
| 细胞系 | 3 个三阴性乳腺癌细胞系：HCC1806、HCC1143、MDA‑MB‑453（论文写作 MDA-MB-453-1） |
| 扰动 | 55 种单药 + 57 种药物组合 |
| 时间点 | 11 个：0、2、4、6、8、10、12、24、36、48、60 h |
| 规模 | 2,528 个蛋白组样本，其中 41 个混合样本、84 个技术重复、49 个生物学重复用于质控；去掉这些后有 2,354 个独立样本 |

## 在论文中的用途

- 选时间点：样本按时间聚成早期（0–6 h）、中期（8–24 h）、晚期（36–60 h）三类，因此 PTDS 选用了 6、24、48 h。
- 检验模型能否预测细胞状态随时间的有序变化。训练、验证、测试按 0.7 : 0.2 : 0.1 随机划分。

## 与本项目的关系

- 这是唯一有密集时间点的数据，可以用来研究 RNA 变化和蛋白变化之间的时间差。LINCS 只有 6 h 和 24 h 两个时间点。
- 3 个细胞系在 LINCS 中按常见命名都没有找到，所以没有直接配对的转录组。
