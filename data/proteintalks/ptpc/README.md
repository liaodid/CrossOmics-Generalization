# PTPC：ProteinTalks 跨癌种数据集

PTPC 是 ProteinTalks 在非乳腺癌上的独立验证数据。总体来源、获取方式和代码输入格式见上一级 [README](../README.md)。

## 内容（摘自论文正文与 Reporting Summary，2026‑10‑15 核对）

| 项目 | 内容 |
|---|---|
| 细胞系 | 5 个：A375（黑色素瘤）、HCT116（结直肠癌）、NCI‑H1975 和 NCI‑H2170（肺癌）、Panc 10.05（胰腺癌） |
| 扰动 | 708 种老药新用化合物 |
| 时间点 | 6 h、24 h |
| 规模 | 2,307 个蛋白组样本，其中 90 个混合样本、86 个技术重复、110 个生物学重复用于质控；去掉这些后有 2,021 个独立样本 |
| 定量蛋白数 | 5,171 |

## 在论文中的用途

在 PTDS 上预训练后，用少样本微调迁移到 PTPC，检验模型跨癌种的泛化能力。
结果为平均 AUPRC 0.41、AUROC 0.77，高于 Geneformer（0.23、0.56）、GeneCompass（0.28、0.72）和 UCE（0.19、0.54）。

## 与 LINCS 转录组的重合（2026‑10‑15，`script/lincs_cell_line_coverage.sh`）

| 细胞系 | LINCS 化合物签名（Phase I / Phase II） | LINCS CRISPR 敲除 | LINCS shRNA |
|---|---|---|---|
| **A375** | 15,453 / 12,050 | 有（Phase II，353 个基因） | 14,800（Phase I） |
| HCT116 | 363 / 0 | 无 | — |
| NCI‑H1975、NCI‑H2170、Panc 10.05 | 按常见命名未找到 | — | — |

**A375 是目前已知唯一一个“ProteinTalks 有蛋白组、LINCS 有大量转录组、且有 CRISPR 数据”的细胞系**，
是验证“转录组 + 蛋白组联合训练”最现实的起点。下一步要核对 PTPC 的 708 种化合物和 LINCS 中 A375 的药物有多少重合。
注意，按药名匹配会漏掉盐型，应按化学结构匹配。
