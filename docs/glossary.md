# 术语表（面向计算机背景读者）

## 总体框架

| 术语 | 含义 | CS 类比 |
|---|---|---|
| 虚拟细胞（virtual cell） | 能预测细胞在干预后状态变化的计算模型 | 学一个状态转移函数 `s' = f(s, a)`，即 world model |
| 扰动（perturbation） | 对细胞施加的干预：敲除基因、加药等 | 上式中的动作 `a` |
| 湿实验 / 干实验 | 在实验室里真实操作 / 只用计算和公开数据 | 线上真实请求 / 离线日志分析 |

## 分子生物学

| 术语 | 含义 | CS 类比 |
|---|---|---|
| 中心法则 | 遗传信息按 DNA → RNA → 蛋白质的方向传递 | 代码仓库 → 调用记录 → 运行中的进程 |
| 基因 | DNA 上编码一个功能产物的片段，人约有 2 万个 | 仓库里的一个函数 |
| mRNA | 基因被“转录”出的拷贝，再被“翻译”成蛋白 | 函数调用时产生的副本 |
| 蛋白质 | 真正执行功能的分子，如酶、受体 | 真正在跑、在干活的进程或对象 |
| 转录组 | 某一时刻细胞中所有基因的 mRNA 含量 | 各函数调用次数的一次快照，形状是 `样本 × 基因` |
| 蛋白组 | 某一时刻细胞中各种蛋白的含量 | 各进程实际占用资源的快照 |
| mRNA 与蛋白的关系 | 相关，但不相等：中间有翻译效率、降解、时间延迟 | 调用次数多，不代表占用的资源一定多 |
| 靶点（target） | 药物直接结合、作用的蛋白 | 药物这个 API 调用的目标对象 |

## 实验与数据

| 术语 | 含义 | 备注 |
|---|---|---|
| 细胞系（cell line） | 从肿瘤分离、可以无限培养的标准化细胞，全世界的实验室用同一株 | 类似标准 benchmark 硬件；换细胞系相当于 domain shift |
| HepG2 | 人肝癌细胞系，常用于药物代谢和肝毒性研究 | HepG2/C3A 是它的克隆衍生株 |
| A375 / MCF7 / A549 | 分别是黑色素瘤、乳腺癌、肺癌细胞系 | LINCS 的核心细胞系，有 CRISPR 数据 |
| CRISPR 敲除（knockout，LINCS 记为 `trt_xpr`） | 从 DNA 层面让一个基因失效 | 删除一个函数 |
| shRNA 敲低（knockdown，`trt_sh`） | 降解 mRNA，使基因表达减弱，但通常不完全 | 给函数加限流 |
| 化合物处理（`trt_cp`） | 加药；多数药物结合靶蛋白，抑制其功能 | 在运行时禁用某个进程 |
| 蛋白降解剂（degrader / PROTAC） | 让细胞把靶蛋白直接降解掉的双功能分子 | 效果更接近“在蛋白层面敲除” |
| 对照（control / vehicle） | 只加溶剂（如 DMSO）、不加药的样本 | 计算变化量时的基准 |
| 剂量 / 时长 | 药物浓度（如 10 µM）/ 处理时间（如 24 h） | 不同剂量和时长的响应不同，可作为模型的条件输入 |
| 响应 / log2FC / Δ | 处理组与对照组之差，通常取 log2 后相减 | 真正要预测的目标是这个差值向量 |
| 生物学重复 / 技术重复 | 独立培养、处理的样本 / 同一样本重复测量 | 前者才能用来估计生物学变异 |
| 批次效应 | 不同批次、不同实验室测量带来的系统偏差 | 数据分布漂移；跨数据集合并时必须处理 |
| bulk / 单细胞 | 一群细胞混在一起测平均值 / 逐个细胞测 | 聚合统计量 / 逐条记录 |

## 测量平台

| 术语 | 含义 |
|---|---|
| L1000 | LINCS 使用的低成本转录组平台，直接测 978 个地标基因，其余推断 |
| Level 5 签名 | LINCS 中把重复样本聚合后得到的 moderated z‑score 向量 |
| 芯片（microarray） | 较早的转录组测量技术，如 GSE51952 |
| RNA‑seq | 测序法测转录组，覆盖全基因 |
| 质谱（MS）/ DIA‑MS | 测蛋白组的主要技术；DIA 是一种数据非依赖采集模式，通量高，但缺失值仍多 |

## 分子与蛋白的表示

| 术语 | 含义 | CS 类比 |
|---|---|---|
| SMILES | 分子结构的字符串写法 | 序列化格式 |
| ECFP4 | 把半径 2 以内的子结构哈希成 2048 位向量的分子指纹 | 对文本做 bag‑of‑n‑grams 后哈希 |
| InChIKey / PubChem CID | 分子的标准化唯一标识 | 主键；跨数据集匹配药物时应使用它，不能用药名 |
| 盐型 | 同一药物的不同盐形式，如 “X (hydrochloride)” | 同一实体的不同字符串写法，按名字匹配会漏 |
| ESM2 | Meta 的蛋白质语言模型，在大量蛋白序列上做掩码预测训练 | 蛋白质版的 BERT |
| UniPert | 把基因（经由蛋白序列）和化合物映射到同一个 256 维空间的模型 | 类似 CLIP 把图像和文本对齐到同一空间 |

## 评价

| 术语 | 含义 |
|---|---|
| 按扰动划分 | 测试集中的药物或基因在训练时从未出现过，避免信息泄漏 |
| 骨架划分（scaffold split） | 按分子骨架分组划分，防止结构几乎相同的分子同时出现在训练集和测试集 |
| 留一细胞系 / 留一药物交叉验证 | 每次留出一个细胞系或一种药物作测试，检验跨环境泛化 |
| Pearson Δ | 预测变化量与真实变化量的相关性；比整体表达谱的相关性更能反映模型能力 |
| AUPRC / AUROC | 分类指标；ProteinTalks 用它们评价药效预测 |
